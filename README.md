# Shadow Courier

A polished, dependency-free HTML5/Canvas vertical slice for a cyberpunk 2D action-puzzle platformer.

## Play

Open `index.html` in a modern browser. The project is static and requires no build step or package install.

### Controls

Desktop: `A/D` move, `W/Space` jump, `Shift` dash, `Q` switch, `R` rewind, `E` interact, `Esc` pause.

Mobile/tablet: touch joystick + Jump, Dash, Switch, Rewind, Use buttons.

## Vertical Slice

- Neon Slums route with modular platforms
- Courier and Shadow modes
- Shadow wall traversal
- 3-second Shadow rewind
- Switch/door puzzles
- Light Guard and Shadow Hunter enemies
- The Mirror boss encounter
- Responsive HUD and mobile controls
- PWA manifest and landscape fullscreen metadata
- Zero external dependencies

## GitHub Pages

Enable Pages for this repository and serve the root folder. The game is designed to run as a static site.
